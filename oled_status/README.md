# OLED Status

Rotating home status pages for the small 128x64 SSD1306 OLED on a Raspberry Pi:
clock, weather, who is home, door locks, heating, bin day, now playing, UPS
battery, a mood face and a starfield screensaver. Alerts such as a water leak,
an unlocked door at night or lights left on interrupt the rotation.

See the Documentation tab for setup and options.
