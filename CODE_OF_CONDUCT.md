# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, keep criticism about the work, and do
not harass anyone. Report problems privately to the maintainer through their
GitHub profile; reports are handled confidentially, and the maintainer may
remove, edit or reject contributions or ban contributors who break this code.
